
# QuickNotes

QuickNotes is a simple, responsive note-taking web application built with HTML, CSS and JavaScript. It allows users to create notes, organise them into Personal, Work and Study categories, search their notes, and delete notes they no longer need. Notes are stored in the browser using localStorage, so they remain available after refreshing the page.

## Features

- Add notes with Personal, Work or Study categories.
- Display notes as individual cards.
- Show each note's category and creation date.
- Validate empty notes and notes longer than 200 characters.
- Delete individual notes.
- Search notes without case sensitivity.
- Display the correct note count.
- Save and restore notes using localStorage.
- Responsive layout for desktop and mobile screens.

## How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/quicknotes-app.git
   ```
2. Open the `quicknotes-app` folder.
3. Open `index.html` in your web browser.

No additional packages or installation are required.
